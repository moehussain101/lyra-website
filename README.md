# Lyra — Mac notch app with a screen-aware AI agent

Lyra lives in your Mac notch, sees your screen, and does tasks by controlling your Mac — clicking, typing, and opening apps.

Website: [Lyra Mac notch app](https://moehussain101.github.io/lyra-website/)

Coming in 2027. This repo holds only the public release website. The Lyra app code stays in its private repo.
